# Store asset production sheet

Generated original brand sources:

- `assets/brand/comboreel-icon-master.png` — 1:1 master, no transparency
- `store/assets/app-icon-512.png` — Google Play app icon
- `store/assets/play-feature-graphic-1024x500.png` — Google Play feature graphic
- Platform icon sets under Android, iOS, and web are generated by
  `dart run tool/generate_brand_assets.dart`.

Capture screenshots only from the release candidate connected to staging. Do not
use generated or composited UI as evidence of product behavior.

Required capture set for the first English listing:

- iPhone 6.9-inch portrait: 1320×2868 (or another currently accepted 6.9-inch
  size in App Store Connect), 5–8 screenshots.
- iPad 13-inch portrait: 2064×2752 or 2048×2732, 3–6 screenshots if iPad remains
  supported.
- Google Play phone: 1080×1920 portrait, 5–8 screenshots.
- Google Play 7-inch and 10-inch tablet: at least 2 native tablet screenshots for
  each supported form factor.

Suggested real-product sequence: discovery hero; series and seasons; vertical
player/subtitles; locked episode choices; My List/Continue Watching; Coins and
Premium; Privacy Center. Avoid prices embedded in artwork, unlicensed content,
ratings/testimonials, competitor marks, device frames that misrepresent the UI,
and status bars containing personal information.

The app icon must not contain transparency. Google’s feature graphic is exactly
1024×500. Apple accepts 1–10 screenshots per device class and does not accept
alpha channels in screenshots.

The master icon was created with the built-in image-generation workflow using
this final brief: an original, centered geometric vertical-film/play/reel mark;
near-black plum background; coral-to-magenta gradient; strong small-size
silhouette; no text, people, transparency, border, watermark, or imitation of an
existing entertainment brand. Platform derivatives are deterministic outputs of
the repository generator and must not be edited separately.
